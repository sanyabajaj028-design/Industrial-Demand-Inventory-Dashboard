# Industrial Demand & Inventory Insights Dashboard

A Python-based interactive dashboard that helps small industrial and retail businesses analyze product demand and manage inventory effectively.

## Features

- Key metrics: Total Products, Low Stock Items, Inventory Value, Total Units Sold
- Low Stock Alerts with shortage calculation
- Top selling products analysis
- Current Stock vs Reorder Level comparison
- Daily demand trend (last 90 days)
- Product filter for focused analysis

## Tech Stack

- **Python**
- **pandas** – Data analysis
- **matplotlib** – Visualizations
- **Streamlit** – Interactive web dashboard

## How to Run

1. Install required libraries:
   ```bash
   pip install pandas matplotlib streamlit
  2. Run the dashboard:
   bash
   python -m streamlit run app.py

Project Overview
This project analyzes sample sales and inventory data to:

Identify products that need reordering
Highlight fast-moving and slow-moving items
Visualize demand trends over time
Provide actionable insights for inventory decisions
